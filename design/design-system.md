# Design System

Tokens: `design-tokens.css` / `design-tokens.json` (generated by `tools/tokens.mjs`; gallery `hifi/tokens.html`). Light and dark. No external fonts or CDNs.

## Principles
Calm, large, quiet. One primary action per screen. Privacy visible but not scary. Status never by colour alone (text + shape). Plain language.

## Colour (light / dark)
Paper #F7F5F0 / #12161D; Surface #FFFFFF / #1B212B; Ink #1C2430 / #ECE9E2; Ink-2 #464F5C / #AEB6C2; Brand "dusk indigo" #36418A / #A9B1F2; Ok #1B6340; Warn #7F4A00; Bad #A3272B; Info #1B5882 (each with soft background). Chart: indigo, ochre, green. Verified contrast results: `screenshots/contrast-results.json` (44 token pairs, 0 failures; 3,018 rendered text elements sampled, 0 below threshold).

## Type
Display: Iowan Old Style, Palatino, Georgia (headings, numerals in stats). Body: system-ui 17px/1.5 (large for tired eyes and small screens). H1 1.9rem (1.55rem mobile), H2 1.4rem.

## Shape and spacing
Radii 8/14/22; cards 18px padding; minimum tap target 48px (primary 64px on home). Spacing base 4px, common 8/12/16/24.

## Components
Buttons (primary, secondary, quiet, danger; sm). Option cards (radio/checkbox as large tappable cards). Status pill (dot + text; Emergency uses a diamond marker). Verification pill (Verified / due / stale / unverified). Banners (info, warn, bad, ok) for consent, break-glass, offline, caution. Masked value (monospace, tinted chip). Journey tracker (horizontal desktop, vertical mobile; terminal Declined/Cancelled banner with reason). Timeline, message bubbles, tables (scroll on small screens), stat tiles, bar rows, SVG bar chart, dialogs (bottom-aligned on mobile), toast with live region, skeleton loader, stepper bars, bottom tab bar with raised primary action, left rail.

## Iconography
Inline 2px-stroke SVG, 22px, rounded caps, always with a text label.

## Charts
Few colours, direct value labels, text alternative via aria-label, grid at 35% opacity. Small-n suppression is a design rule, not a styling choice.

## Motion
Minimal; skeleton shimmer disabled with reduced-motion.

## Content rules
No names/IDs in notifications, titles or URLs. "Synthetic demonstration data" banner on every prototype screen. Reasons use controlled lists plus optional note (no identifiers).
