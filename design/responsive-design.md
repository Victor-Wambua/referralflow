# Responsive Design

Mobile/tablet first for clinicians; desktop for coordinators and admins. Breakpoint 900px: left rail (240px) becomes a bottom tab bar (5 items, safe-area padding); two/three/four-column grids collapse to one (stat tiles keep two columns); tracker turns vertical; dialogs anchor to bottom; sticky action bar sits above the tab bar. Tables scroll horizontally in a container. Tested viewports: 390x844 (phone) and 1440x900 (desktop); tablet (768) uses the mobile pattern with wider cards. Low-connectivity: no web fonts, no images, small payload (prototype about 85 KB of HTML, JS and CSS), offline banner and encrypted outbox with visible sync state, optimistic confirmation labelled "Saved on device". Primary mobile action is thumb-reachable (bottom bar, sticky Continue/Send).
